Инварианты
нельзя отправить заявку самому себе;
нельзя создать две активные заявки одной направленности;
дружба не может существовать только для одной стороны;
принятие заявки должно создать дружбу и обратную подписку атомарно;
отклонение заявки не отменяет подписку инициатора;
повтор команды не должен создавать дублирующие связи.
